# 🕐 Turtle Clock

Orë analoge e vizatuar me Python turtle — port në Canvas që tregon orën reale të vizitorit, me akrepa orë/minutë/sekondë që lëvizin live dhe datën poshtë, si origjinali.

## 🚀 Si ta hapësh

Hap `index.html` në browser dhe kliko **Live Demo** — ora tregon automatikisht orën reale të pajisjes tënde.

## 📁 Struktura

```
Turtle-Clock/
├── index.html
├── demo/  (ora analoge canvas me orën reale)
├── original/Turtle_Clock.txt  (origjinali turtle, i paprekur)
├── README.md
└── PROVENANCE_LICENSE.txt
```
